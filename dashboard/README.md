# Dashboard

RecordBridge ships two dashboard paths.

## 1. Plotly (default — license-free)

A single self-contained HTML file is generated by the pipeline:

```bash
make dashboard        # or: recordbridge dashboard
```

This writes `dashboard/recordbridge_dashboard.html` (open it in any browser). It
shows the data-quality KPI, duplicate-resolution donut, exceptions by field,
before/after funnel, quality-over-batches trend, and detection accuracy. No
license or external service is required.

## 2. Power BI (enterprise option)

For an institutional deployment you can point Power BI Desktop at the same SQLite
database (or a SQL Server backend):

1. **Get Data → SQLite / SQL Server** and connect to `data/recordbridge.db`.
2. Load the tables: `upload_batches`, `validation_errors`, `duplicate_pairs`,
   `students_clean`, `correction_log`.
3. Recommended visuals (mirroring the Plotly dashboard):
   - **Card:** `passed / total_rows` from `upload_batches` → Data Quality Score.
   - **Donut:** count of `duplicate_pairs.resolution`.
   - **Bar:** count of `validation_errors` by `field`.
   - **Line:** quality score by `upload_batches.run_at` (quality over batches).
   - **Table:** `correction_log` for the audit trail.

A `.pbix` file is intentionally not committed (it is a binary, license-bound
artifact); the steps above reproduce it from the open database.
